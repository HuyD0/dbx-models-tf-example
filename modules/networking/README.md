# networking

VNet-injection network for an Azure Databricks workspace: one VNet with
delegated public ("host") and private ("container") subnets and the NSG
associations Databricks requires. Outputs feed straight into
`modules/databricks-workspace`.

Interface tables below are generated by
[terraform-docs](https://terraform-docs.io) (`pre-commit run terraform_docs`).
