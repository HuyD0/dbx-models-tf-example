# model-serving

The AI-gateway layer of the platform. This module manages what Terraform
*can* manage, and documents/feeds what it cannot:

- **External endpoints** (`databricks_model_serving` + inline
  `ai_gateway {}`): Azure OpenAI via Entra ID by default, optional direct
  Anthropic entries with secret-referenced API keys. Every endpoint gets
  usage tracking, inference tables, and the `gateway_defaults` rate
  limits/guardrails from `model_defaults.yaml` unless the workspace
  overrides them.
- **Model allowlist**: `lifecycle` preconditions fail the plan for any
  endpoint whose model is missing from `allowed_external_models` in
  `model_defaults.yaml`.
- **Fallback router** (optional): one endpoint, two served entities,
  `fallback_config` — because Databricks forbids chaining one
  external-model endpoint to another.
- **Endpoint ACLs**: a single authoritative `databricks_permissions`
  resource per endpoint (multiple resources on one endpoint overwrite
  each other).
- **Agent-waste alerts** (optional, `monitoring.tf`): `databricks_alert_v2`
  resources generated from the endpoint catalog that page on retry
  loops, elevated error rates, callers hammering deny-listed models and
  (opt-in) sessions repeatedly feeding tool-call errors back to the
  model. Set `agent_waste_monitors`; see `docs/agent-spend-waste.md`.
- **Pre-provisioned `databricks-*` foundation endpoints** cannot be
  created or updated by Terraform (reserved prefix). They are governed
  out-of-band by `scripts/apply-ai-gateway.sh`, driven by the same
  `model_defaults.yaml` and re-run on every apply via `terraform_data`
  in `modules/workspace-stack`. That deny-list is **fail-open** for newly
  released endpoints — see the warning in `model_defaults.yaml`.

`model_defaults.yaml` is the single source of truth (schema-validated in
pre-commit and CI). Unit tests for the validations and preconditions live
in `tests/` — run `terraform init -backend=false && terraform test` here;
CI runs them on every PR with mocked providers.

Interface tables below are generated by
[terraform-docs](https://terraform-docs.io) (`pre-commit run terraform_docs`).
