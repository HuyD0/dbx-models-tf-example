# databricks-workspace

The Azure Databricks workspace itself (Premium SKU, VNet-injected,
optional infrastructure encryption and Secure Cluster Connectivity) plus
the Access Connector whose system-assigned managed identity Unity Catalog
uses to reach ADLS Gen2.

Interface tables below are generated by
[terraform-docs](https://terraform-docs.io) (`pre-commit run terraform_docs`).
