# unity-catalog

Unity Catalog wiring for one workspace: the ADLS Gen2 storage account and
container, metastore assignment, storage credential + external location
backed by the Access Connector MSI, the `main` and/or inference catalogs,
the `model_serving_logs` schema, and scoped group grants (write, consumer,
reader) — least-privilege by construction, with the reasoning documented
next to each grant in `main.tf`.

Requires both a workspace-scoped `databricks` provider and an
account-scoped `databricks.accounts` alias (metastore assignment and group
lookups happen at the account level).

Interface tables below are generated by
[terraform-docs](https://terraform-docs.io) (`pre-commit run terraform_docs`).
